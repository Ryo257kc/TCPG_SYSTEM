## 実装時の注意

- 郵便番号は現 DB に列が見当たらないため、代用しない
- `office_number` は事業所番号であり郵便番号ではない
- 未確定値は Excel にも書き込まない
- 既存の年度更新 Web 画面の値と一致することを前提に流し込む
