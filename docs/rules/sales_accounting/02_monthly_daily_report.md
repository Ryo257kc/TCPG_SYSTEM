# 月間日報・月次処理ルール

## 対象

- `/staff/office/store_daily_report/daily_summary`
- 月間日報PDF
- `app/Http/Controllers/StaffPortal/Office/StoreDailyReportController.php`
- 関連ビュー

## 役割

月間日報は、店舗売上を月次確定する前の確認画面。
月次確定後に、その数字を `mx_monthly_closings` と `mx_journal_entries` に保存する。

## 月次入力

- 入力するのは、さくら・ひなたのレセ負担金。
- 保険負担は月間日報の集計値を自動表示する。
- 月次確定済の場合は編集不可。
- 保存先は `mx_monthly_closings`。入力用の `authority` と月次確定用の `authority` は分ける。

## 月次確定

- 対象月は月初日で保存する。
- 処理日は月次処理日として保存する。
- 月次確定時に売上仕訳を作成・更新する。

## 作成する仕訳

- 窓口: 借方 `現金` / `保険窓口負担`、貸方 `窓口収入` / `保険窓口負担`。
- 自費: 借方 `現金` / `自費`、貸方 `自費収入` / `自費`。
- 経費: 借方 `消耗品費` / `店舗経費`、貸方 `現金` / `店舗経費`。

## 月次解除

- 管理者のみ。
- 月次確定行を削除する。
- 削除してよい仕訳は、月次確定で作成した売上仕訳だけ。
- レセ取込や往診取込など別経路で作成された仕訳は消さない。

## 注意

- 月間日報と月報は別帳票。名前だけ変えて同じ扱いにしない。
- 店舗未選択の場合、店舗別帳票の印刷ボタンは原則出さない。
- 正しい流れは、月間日報で確定、仕訳へ保存、売上一覧で表示。
