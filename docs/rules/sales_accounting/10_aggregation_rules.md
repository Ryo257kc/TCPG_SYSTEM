# 売上・月次 集計ルール

## 原則

売上一覧と売上PDFは、仕訳テーブル `mx_journal_entries` を表示する。
日報、レセ、往診、入金確認の元データから、売上一覧側で売上を再計算しない。

正しい数字を作る場所は月次処理または取込処理。
月次処理・取込処理で作成された仕訳を、売上一覧で確認する。

## 日付ルール

- `month_date` は対象月の月初日。
- `occurred_at` は原則として対象月の月末日。
- 売上一覧の対象月絞り込みは `month_date` で行う。
- 発生日だけで対象月を判定しない。

## 店舗売上 月次処理

月間日報で集計した確定数字を、月次確定時に `mx_journal_entries` へ保存する。
保存後の売上一覧は、その仕訳を表示するだけ。

### 窓口収入

- 借方勘定科目: `現金`
- 借方品目: `保険窓口負担`
- 借方税区分: `対象外`
- 貸方勘定科目: `窓口収入`
- 貸方品目: `保険窓口負担`
- 貸方税区分: `非課売上`
- 金額: 月間日報で確定した店舗別の保険窓口負担

### 自費収入

- 借方勘定科目: `現金`
- 借方品目: `自費`
- 借方税区分: `対象外`
- 貸方勘定科目: `自費収入`
- 貸方品目: `自費`
- 貸方税区分: `課税売上10%`
- 金額: 月間日報で確定した店舗別の自費

### 店舗経費

- 借方勘定科目: `消耗品費`
- 借方品目: `店舗経費`
- 借方税区分: `対象外`
- 貸方勘定科目: `現金`
- 貸方品目: `店舗経費`
- 貸方税区分: `対象外`
- 金額: 日報側の店舗経費集計

## レセ負担金

月間日報入力で手入力するのは、さくら・ひなたのレセ負担金のみ。
保険負担は月間日報の集計値を自動表示する。

月次確定済の場合、月間日報入力は編集不可。
確定後の数字を表示側で再計算しない。


## 往診自費の扱い

往診窓口の入金名称は、`ｼﾞﾋ` と `ｼﾞﾋｺｳｻﾞ` を別物として扱う。
曖昧一致 `LIKE '%ｼﾞﾋ%'` は禁止。必ず完全一致または明示的な `IN` で分岐する。

- `ｼﾞﾋ`: 自費収入として売上一覧の自費に含める。金額は `cash_collected_amount` を使う。
- `ｼﾞﾋｺｳｻﾞ`: 売上一覧の自費、窓口、個人振込に含めない。月次売上仕訳を作成しない。
- `ｼﾞﾋ` と `ｼﾞﾋｺｳｻﾞ` を同じ条件でまとめない。

往診窓口の月次仕訳は、Accessの追加クエリと同じ考え方で入金名称ごとに明示する。
「特定名称以外を全部入れる」条件は禁止。

- 保険窓口負担: `ｵｳｼﾝﾏﾄﾞｸﾞﾁ` と `ﾁｮｳｾｲ` を対象にし、金額は `cash_collected_amount` を使う。
- 個人振込: `ｺｼﾞﾝﾌﾘｺﾐ` を対象にし、金額は入金額ではなく現金回収額 `cash_collected_amount` を使う。

## 売上一覧の集計条件

売上一覧は `mx_journal_entries` の勘定科目・品目・部門を見て集計する。

- 保険請求額: 借方品目が `一般保険請求`、`後期高齢保険請求`、`医療助成請求` の仕訳。
- 保険窓口負担: 貸方勘定科目が `窓口収入`、かつ貸方品目が `個人振込` ではない仕訳。
- 個人振込分: 貸方勘定科目が `窓口収入`、かつ貸方品目が `個人振込` の仕訳。
- 自費: 貸方勘定科目が `自費収入`、かつ借方勘定科目が `現金` の仕訳。
- 店舗経費: 貸方品目が `店舗経費` の仕訳。
- 合計金: 保険請求額 + 保険窓口負担 + 個人振込分 + 自費。
- 銀行入金額: 保険窓口負担 + 自費 - 店舗経費。

## 月次解除

月次解除で削除してよい仕訳は、店舗月次処理で作成した以下の仕訳のみ。

- `現金` / `保険窓口負担` から `窓口収入` / `保険窓口負担` の仕訳。
- `現金` / `自費` から `自費収入` / `自費` の仕訳。ただし `journal_breakdown` が `yyyymmレセ%` のものは削除しない。
- `消耗品費` / `店舗経費` から `現金` / `店舗経費` の仕訳。

レセ取込、往診取込、入金確認、小口現金など、別経路で作成された仕訳は削除しない。

## 禁止

- 売上一覧側で不足分を補完しない。
- 店舗名や会社名で勝手に合算条件を追加しない。
- 仕訳に存在しない売上を表示だけで足さない。
- Accessと異なる集計式を新規に作らない。
- 条件が不明な場合は、変更前に確認する。

## 未収入金

未収入金は売上一覧に混ぜず、専用ページで管理する。
入口はダッシュボードの `未収入金`、ルートは `/staff/office/sales/uncollected`。

- 未収入金一覧: `/staff/office/sales/uncollected`
- 月別印刷: `/staff/office/sales/uncollected/print`
- 個別印刷: `/staff/office/sales/uncollected/detail-print`

売上金額として発生しているものは売上に含めるが、現金回収・銀行入金額には含めない。
未収は回収状況を確認するための別管理とする。

未収入金の仕訳・入金確認は、売上一覧側で補完しない。
数字が合わない場合は、未収入金ページ、入金確認、仕訳作成元を先に追跡する。
