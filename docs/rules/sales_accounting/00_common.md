# 売上・仕訳 共通ルール

## 目的

売上表示、月次処理、仕訳作成の数字が分岐しないようにする。
Access運用と同じく、月次で確定した数字を仕訳に入れ、売上一覧とPDFは仕訳を表示する。

## 基本ルール

- 売上一覧は `mx_journal_entries` を集計・表示する。
- 売上一覧やPDFで、日報・レセ・往診から独自に再計算しない。
- 月間日報で正しい数字を作り、月次確定で `mx_monthly_closings` と `mx_journal_entries` に保存する。
- 月次確定済の数字を別ロジックで再計算しない。
- 月次解除で削除してよいのは、その月次処理で作った売上仕訳だけ。
- 表示側にある計算は、差額などの単純表示に限る。

## データの流れ

1. 日報・レセ・往診の入力データを作る。
2. 月間日報で店舗別の窓口、保険負担、自費、経費を確認する。
3. 月次入力でレセ負担金を保存する。
4. 月次確定で `mx_monthly_closings` に確定情報を保存する。
5. 月次確定で `mx_journal_entries` に売上仕訳を作成・更新する。
6. 売上一覧と売上PDFは `mx_journal_entries` を表示する。

## 変更前に止まる条件

- 月間日報と売上一覧の数字が一致しない。
- 売上一覧側で日報・レセ・往診から再計算しようとしている。
- 月次確定済の月を編集しようとしている。
- 月次解除で関係ない仕訳まで消える可能性がある。
- 店舗別の数字を勝手に合算する前提になっている。
