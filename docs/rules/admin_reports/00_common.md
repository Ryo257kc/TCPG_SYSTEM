# 管理レポート 共通ルール

## 対象画面

- `/admin/reports`
- `/admin/reports/santei`
- `/admin/reports/bonus-payment`
- `/admin/reports/labor-insurance`
- `/admin/reports/rishoku`

## 基本方針

管理レポートは保存済みデータを確認・出力する画面。
給与、賞与、勤怠、社保、労保などの計算ロジックをレポート側で新しく作らない。

## データの扱い

給与・賞与に関する数値は給与・賞与側の保存値を表示する。
勤怠に関する数値は勤怠側の保存値、または共通集計ロジックを使う。
レポート専用の再計算で過去データが変わる作りにしない。

## 帳票・CSV・Excel

帳票、CSV、Excelで同じ項目を出す場合は、同じ取得条件を使う。
画面表示と出力で条件を分けない。

## 触らないこと

- レポート表示のために給与・賞与・勤怠データを更新しない。
- 出力画面だけ独自計算にしない。
- 法改定が関係する値は、根拠日と参照元を確認せず変更しない。
