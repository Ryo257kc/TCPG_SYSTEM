# 有給管理 共通ルール

## 対象画面

- `/admin/paid-leave`
- `/staff/attendance/paid-leave`

## 基本方針

有給管理は有給付与、使用、残日数の基準データを管理する。
給与計算や勤怠反映で有休残を表示する場合も、有給管理の考え方とずれないようにする。

## データの流れ

勤怠管理で有休使用を登録する。
有給管理で使用日数・残日数を管理する。
給与計算では保存済み・反映済みの有給情報を表示する。

## 表示対象

スタッフマスタの有休対象チェックや雇用状況を考慮する。
業務委託や有休対象外の人を選択肢に出す場合は、理由を確認する。

## 触らないこと

- 給与再計算側だけで有休残を独自計算しない。
- 有休対象外の人に勝手に有休を付与しない。
- 喪失済みの履歴を削除して過去が追えない状態にしない。
