# 有給管理 管理画面ルール

## 対象

- `/admin/paid-leave`

## 基本方針

有給管理は付与、使用、喪失、残日数を管理する。
給与計算や勤怠画面で表示する有休残は、有給管理と一致すること。

## 対象者

スタッフマスタの有休対象チェックを考慮する。
有休対象外の人を選択肢に出さない。
退職や業務委託への変更があった場合、必要に応じて喪失処理で残日数を0にする。

## 喪失

喪失は履歴として残す。
過去の有給情報を削除して帳票や給与確認が追えなくなる状態にしない。

## 触らないこと

- 有休対象外の人へ自動付与しない。
- 過去の使用日や残日数を表示都合で消さない。
- 給与側だけで有休残を補正しない。
