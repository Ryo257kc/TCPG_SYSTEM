# 請求関連 触らないルール

## 禁止

- Accessで一致確認済みの集計条件を、確認なしに変更しない。
- old カラムへ戻す処理を追加しない。
- 売上表示側で請求、入金、未収を再計算しない。
- 月次済みデータを保存、削除できるようにしない。
- CSVの「?」を自動補正して取り込まない。
- 店舗名、店舗略称、部門番号を推測で補完しない。

## 迷ったとき

- まず Access の条件、既存DBの値、現在のLaravelコードの順で確認する。
- 数字が合わない場合は表示側で合わせず、作成元のデータと条件を追う。
- 請求関連の変更は、売上、月次、仕訳への影響を必ず確認する。
