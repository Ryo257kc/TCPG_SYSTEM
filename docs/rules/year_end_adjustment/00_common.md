# 年末調整 共通ルール

## 対象

年末調整は管理側の `admin/work/year-end-adjustments` を中心に作る。
スタッフ公開側は、管理側で申請・計算・添付・帳票の流れが固まってから公開する。

## 基本方針

- 年調申請の状態管理と、年調計算結果は分けて扱う。
- 申請の入口は `staff_year_end_applications`。
- 計算結果は既存の `mx_nen_tyo` に保存する。
- 保険控除は既存の `mx_hoken` を使う。
- 扶養情報は既存の `mx_fuyo` を使う。
- 給与・賞与・扶養・保険は、帳票表示用に作り直さず、既存テーブルの値を参照する。
- 確定済み、処理済みの過去データを勝手に再計算・上書きしない。

## 公開状態

スタッフポータルの年末調整カードはまだ非表示。
管理側で確認できる状態にしてから、公開可否を判断する。
