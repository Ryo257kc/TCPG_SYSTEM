# ダッシュボード 共通ルール

## 対象

- /staff/dashboard
- resources/views/staff_portal/dashboard/index.blade.php

## 基本方針

- ダッシュボードはスタッフポータルの入口。見た目の整理より、業務上のまとまりと権限の意味を優先する。
- 大見出しの表示条件は、原則としてスタッフマスタの権限名称と対応させる。
- ただし、業務上の理由で特定メニュー内に置いているカードは、勝手に別セクションへ移動しない。
- 全権管理者はフルアクセス。全セクション、全カードを表示できること。

## 権限と表示

- 往診: 往診スタッフ権限。往診日報、往診月報など、本人の往診業務に使う。
- 事務所: 事務所権限。請求関連、店舗日報、売上関連、事務業務、打刻一覧をまとめて表示する。
- 往診事務: 往診事務権限。患者一覧、往診入金管理、距離集計、ダウンロードなどを表示する。
- 往診売上: 往診事務内に置く。ただしカード表示は往診売上権限で制御する。
- 往診管理: 往診管理権限。管理用の往診日報一覧、領収一覧などを表示する。
- 店舗管理: 店舗管理権限。シフト変更、勤怠管理、有休管理などを表示する。
- 店舗日報権限は、日報内で表示するスタッフの制御用。ダッシュボードの表示条件には使わない。

## 禁止

- 店舗日報を店舗日報権限だけでダッシュボードに単独表示しない。
- 事務所メニュー内の項目を、確認なしに別セクションへ移動しない。
- 往診売上カードを、確認なしに往診事務セクション外へ移動しない。
- hidden => true の準備中カードを、確認なしに公開しない。
- route => dashboard の仮リンクを、表示状態のカードに残さない。

## 確認

- 変更後は php artisan view:cache を通す。
- 日本語破損がないことを確認する。
- 準備中カードが表示されていないことを確認する。
