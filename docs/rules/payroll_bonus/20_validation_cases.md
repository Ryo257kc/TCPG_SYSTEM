# Access一致 検証ケース

## 目的

改修後にAccess運用時と違う計算になっていないか確認するための基準値を残す。

## 使い方

- 正しいと確認済みの年月、スタッフ、項目、期待値を書く。
- 計算式を変更した場合は必ず検証する。
- 差異が出た場合は、Laravel側が間違いか、Access時代の手修正か、法改定かを分けて記録する。

```md
### YYYY/MM/DD支給 No.XXX 氏名

前提:
- 雇用区分:
- 支給日:
- 勤怠月:

- 支給合計:
- 課税支給合計:
- 非課税支給合計:

- 雇用保険:

確認元:
- Access

- 明細

メモ:
- 
```

## 既知の重要ケース

### 2026/04/20支給 管理手当

確認すること:

- 管理者自身の売上が100万円を超えた場合のみ対象。
- 管理者を除く売上で、60万円を超えた人だけを計算対象にする。
- 60万円超過分ではなく、対象者の売上に対して2%。

### 賞与 社保合計

確認すること:

- 子ども支援金が社保合計に含まれる。
- 給与と賞与で社保合計の式が違わない。

### 業務委託

確認すること:

- 雇用保険、社会保険、所得税、住民税、労災が計算されない。
- 手入力の調整控除は保存される。

### 賃金台帳

確認すること:

- 役員報酬は `allowance_amo_2`。
- 子ども支援金が表示される。
- 小数が必要な勤怠項目を勝手に整数表示しない。
