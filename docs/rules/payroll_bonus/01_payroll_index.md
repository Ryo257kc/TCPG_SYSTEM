# 給与計算ページ ルール

対象:

- `resources/views/admin_v2/work/payroll/index.blade.php`
- `resources/views/admin_v2/work/payroll/page_script.blade.php`
- `resources/views/admin_v2/work/payroll/page_state_runtime.php`
- `App\Http\Controllers\Admin\V2\PayrollV2Controller`

## ページの役割

給与データの表示、手入力、勤怠反映、売上反映、再計算、個別計算、確定を行う。

## ボタンの意味

- 保存: 手入力値を保存し、合計値を正本の式で作り直す。
- 勤怠反映: 勤怠から給与へ勤怠情報を反映する。
- 再計算: 給与マスタ、勤怠、社会保険、税などから再計算する。手入力値を不用意に消さない。
- 往診手当: 往診売上に基づく歩合手当、管理手当を計算する。
- 割増・控除: 残業、休日出勤、欠勤控除、遅早控除などを計算する。
- 雇用保険: 雇用保険だけを計算する。
- 所得税: 所得税だけを計算する。
- 確定: 給与を確定し、必要な反映を止める。

## 手入力の扱い

- 手入力された項目は保存できること。
- 保存時に給与マスタの値へ勝手に戻さない。
- 再計算や個別計算で上書きされる項目は、理由を明確にする。

## 勤怠と有休

- 有休残日数は勤怠反映ルートで扱う。
- 同じ月・同じスタッフで、個別反映と一括反映が違う式にならないようにする。
- 有休管理の残日数と給与計算の有休残日数が食い違う場合は、給与側ではなく反映元を確認する。

## 業務委託

- 業務委託は税・社保・労保系の計算を走らせない。
- 支給項目はスタッフと同じ画面で扱ってよい。
- 調整控除など手入力項目は保存できること。

## CSS

- 給与・賞与で共通の部品は `payroll.css` を使う。
- 給与だけの売上集計テーブルなど、そのページ専用はBlade内styleでよい。
