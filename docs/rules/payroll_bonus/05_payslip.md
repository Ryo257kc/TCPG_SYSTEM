# 明細表示 ルール

対象:

- `resources/views/shared/payroll/payslip_item.blade.php`
- 給与計算ページ内の明細プレビュー
- 賞与計算ページ内の明細プレビュー
- スタッフポータルの給与明細表示

## 基本方針

- 給与・賞与・スタッフポータルで同じ共通明細を使う。
- ラベルだけで判断せず、表示元カラムを確認する。
- 役員報酬は `allowance_amo_2`。
- 子ども支援金は控除欄に表示する。

## 注意

- `allowance_2` や `officer_com` は旧カラム。使わない。
- 表示名を変える場合は、賃金台帳、給与計算、賞与計算との整合を確認する。
- 支給項目と控除項目の位置を勝手に入れ替えない。
