# 勝手に触らないもの

## 目的

給与・賞与で、確認なしに変更してはいけないものを固定する。

ここにあるものを変更する場合は、先に理由、影響範囲、検証方法を確認する。

## 絶対に守ること

- Access時代と一致確認済みの計算を、理由なく変更しない。
- 給与と賞与で同じ意味の合計計算を別々に作らない。
- 帳票側で支給、控除、差引支給額を再計算しない。
- 賃金台帳用の別データを作らない。
- 業務委託の税、社保、雇用保険、所得税を勝手に計算しない。
- 保存ボタンで手入力値を消さない。
- 個別計算ボタンで給与マスタを勝手に再取込しない。
- 日本語ラベルを推測で直さない。
- 一括置換で日本語を直さない。
- DB・スキーマ関連の処理を`try/catch`で握りつぶして空配列やfalseにフォールバックしない
  （詳細は下の「DB・スキーマのエラーを握りつぶさない」）。

## DB値そのまま表示の帳票

以下は原則としてDB保存値を表示する。

- 賃金台帳
- 個人賃金台帳
- 明細
- 振込一覧
- 会社負担一覧
- 委託報酬帳票

表示用の集計が必要な場合でも、給与・賞与の保存値と違う結果にならないようにする。

## 旧カラムを復活させない

- `x_officer_com`
- `x_allowance_1`〜`x_allowance_16`（手当名称の旧テキスト列。現行は`mx_allowance`マスタ）
- `x_department_no_old`
- `x_staff_name_old`

これらは旧カラム、退避カラムとして扱う。

必要に見えても、まず現行カラムとラベルの関係を確認する。

## DB・スキーマのエラーを握りつぶさない

テーブル名・カラム名が存在しない、接続できない等の**本来起きてはいけないエラー**を
`try { ... } catch (\Throwable) { return []; }`のような形で握りつぶし、空配列や`false`に
フォールバックして処理を続けない。

- 実際にあった事故：`StaffPortal\PayrollController`が手当名マスタを`t_allowance`という
  存在しないテーブル名で参照していたが、`resolveAllowanceDefinitionsBySlot()`・
  `resolveAllowanceDefinitionsOrdered()`・`payrollAllowanceHasColumn()`の3箇所が
  すべて例外を`catch (\Throwable)`で空扱いにしていたため、会社ごとの手当名カスタマイズ機能が
  何ヶ月も静かに無効化されたまま誰も気づかなかった（2026年8月に発覚、`mx_allowance`へ修正）。
- 握りつぶさなければ、テーブル名を間違えた瞬間に例外が出て、コード修正時にすぐ気づけたはず。
  フォールバックはこの「気づく機会」を潰してしまう。
- 区別すること：「この会社にはまだ手当マスタの行が0件」のような**正常な空データ**は
  フォールバックではなく、単なる空の結果として扱ってよい。禁止しているのは
  「クエリ・スキーマ確認そのものが失敗した」場合に例外を隠すこと。
- コードレビュー・調査時は、DB/スキーマ呼び出しを囲む`catch (\Throwable)`（または広すぎる
  catch）を見つけたら、この握りつぶしパターンでないか必ず確認する。

## 手当名称マスタのテーブル名

会社ごとの手当名カスタマイズ（`allowance_name`/`slot_no`/`amount_column_key`）は `mx_allowance` テーブル。
`t_allowance`という名前ではない（2026年8月まで`StaffPortal\PayrollController`が誤って`t_allowance`を
参照しており、テーブルが存在しないため毎回例外→catchで空扱いになり、カスタマイズ機能が
サイレントに無効化されていた。`mx_allowance`に修正済み）。

## 給与・賞与で分けないもの

- 社保合計
- 子ども支援金を含む社会保険系の合計
- 控除合計
- 差引支給額
- 表示整形

給与と賞与で差が必要な場合は、差分だけを明示する。

## 触る前に止まる条件

以下に当てはまる場合は、変更前に確認する。

- Accessの計算式とLaravelの計算式が違う。
- DB保存値と画面表示値が違う。
- 同じボタンを複数回押すと結果が変わる。
- 給与マスタの値で手入力値が上書きされる。
- 業務委託に控除、税、社保が入る。
- 旧カラム名が必要に見える。
- 帳票だけ数字が違う。
- 日本語が文字化けしている。
