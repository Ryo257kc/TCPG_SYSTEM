# 請求一覧 共通ルール

## 対象画面

- `/admin/work/billing-list`
- `/admin/work/billing-list/{invoiceId}/print`

## 基本方針

請求一覧は請求データと明細を管理する画面。
請求書の表示、印刷、保存値がずれないようにする。

## データの扱い

請求ヘッダーと請求明細は役割を分ける。
請求先、請求日、対象月、社名などの共通情報はヘッダー側で管理する。
品目、数量、単価、金額などの行ごとの内容は明細側で管理する。

## 印刷

印刷画面は保存済みデータを表示する。
印刷時だけ別計算や別名変換をしない。

## 触らないこと

- 請求確定済みデータを表示の都合で自動変更しない。
- ヘッダー項目を明細ごとに重複保存しない。
- 印刷だけで金額を再計算しない。
