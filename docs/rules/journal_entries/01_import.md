# 仕訳帳 取込ルール

## 対象

- `/admin/work/journal-entries/import`

## 基本方針

取込前に対象年月と会社を確認する。
押した月や会社が分からないまま取り込まれるUIにしない。

## 取込中表示

件数が多いと止まって見えるため、取込中であることを画面に表示する。
二重送信を防ぐ。

## CSV・freeeデータ

freee由来の仕訳は、管理番号、発生日、勘定科目、部門、取引先、品目、摘要を重要条件として扱う。
不足している行をコード側で勝手に補完しない。

摘要（取引内容）等のセル内に改行を含む行が来ることがあるため、CSVパースは行単位のstr_getcsv()ではなく、
クォート内改行を正しく1レコードとして扱えるfgetcsv()ベースで行う（行分割方式に戻すと、改行を含む行の後続列が
すべてズレて取り込まれる）。

借方金額・貸方金額は、空欄は許容するが、非空かつ数値として解釈できない値は取込対象外とし、件数を画面に出す。
手動編集（金額欄）が数値以外を保存エラーで弾いているのに対し、取込だけ黙ってnullで保存する状態に戻さない。

## 触らないこと

- 0円になった既存仕訳を取込処理で勝手に削除しない。
- 不明な入金名称や摘要を推測で除外しない。
- `報酬計算除外` の意味を取込時に変えない。
