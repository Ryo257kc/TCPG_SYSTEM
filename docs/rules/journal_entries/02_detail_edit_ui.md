# 仕訳帳 詳細編集UIルール

## 対象

- `/admin/work/journal-entries`
- 詳細の「開く」表示

## 基本方針

詳細編集はAccessの表形式に近く、同じ項目は同じ列に並ぶようにする。
行ごとに情報がばらけて見落としが起きるUIにしない。

## 共通欄

同じ仕訳内訳で共通する項目は上部の共通欄へ置く。
共通欄を編集して保存した場合、対象行すべてに反映する。

例:

- 発生日
- 仕訳内訳
- 摘要
- 管理番号
- 取引先
- チェックボックス類

## 明細行

借方、貸方、金額、品目、メモなど行ごとの内容は表形式で表示する。
削除と追加は `+` / `-` など幅を取らない操作にする。

## 取引先

freeeでは1仕訳につき取引先は1つの考え方。
借方取引先、貸方取引先を別の入力項目として増やさない。

## 触らないこと

- フィルタ条件をUI整理のついでに変えない。
- 管理番号フィルタや会社フィルタを勝手に追加しない。
- 開く画面の表示改善で集計条件を変更しない。
