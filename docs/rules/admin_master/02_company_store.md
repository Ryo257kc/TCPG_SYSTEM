# 管理マスタ 会社・店舗ルール

## 対象

- `/admin/master/company`
- `/admin/master/store`

## 基本方針

会社・店舗マスタは帳票、給与、年末調整、売上、仕訳、勤怠の参照元。
画面側で会社名、住所、法人番号、店舗名を固定文字にしない。

## 会社情報

年末調整PDFでは会社名、会社住所、法人番号を会社・店舗マスタから取得する。
スタッフの所属店舗コードから会社情報をたどる場合、コードのゼロ埋め差異に注意する。

## 店舗情報

店舗名、店舗略称、部門名、store_category は用途が違う可能性がある。
売上、日報、仕訳、レセ請求でどの名称を使うかを推測で入れ替えない。

## 社保・労保・市区町村

会社マスタの社会保険、労働保険、市区町村情報はレポートや帳票で使う。
年度や適用期間がある値は過去分を上書きしない。

## 触らないこと

- 店舗名を表示用の都合だけでDB値ごと変更しない。
- 部門コード、店舗コード、店舗略称を同じ意味として扱わない。
- 会社情報を年末調整PDFや帳票内に直接書かない。
