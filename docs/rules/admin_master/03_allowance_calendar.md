# 管理マスタ 手当・カレンダールール

## 対象

- `/admin/master/allowance`
- `/admin/master/calendar`

## 手当

手当マスタは給与・賞与計算の根拠。
支給、控除、課税、非課税、社保対象、固定残業対象などの判定に関係する。

欠勤控除、遅早控除など控除系の項目はマイナス金額として扱う。
ただし過去に保存済みの値を一括で変換しない。

## 交通費

`traffic_pay` は給与マスタの交通費。
基本は非課税通勤費として扱う。
課税・非課税の判定は金額や距離の条件が絡むため、勝手に課税交通費へ入れない。

`traffic_day` は日額交通費。
給与計算画面でも確認できるとよい。

## カレンダー

カレンダーは勤怠、休日、所定時間、有休、給与反映に影響する。
祝日取込や休日区分変更は対象年月を確認する。

## 触らないこと

- 手当名を勝手に変えない。
- Access時代の項目名とDBカラム名の対応を確認せず置き換えない。
- カレンダー変更を過去月へ無断反映しない。
