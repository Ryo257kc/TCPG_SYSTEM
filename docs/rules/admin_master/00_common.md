# 管理マスタ 共通ルール

## 対象画面

- `/admin/master/staff`
- `/admin/master/company`
- `/admin/master/store`
- `/admin/master/allowance`
- `/admin/master/calendar`

## 基本方針

管理マスタは給与、勤怠、年末調整、売上など複数画面の元情報になる。
表示名だけの修正に見えても、他画面の計算や表示に影響する可能性があるため、変更前に参照先を確認する。

## スタッフマスタ

スタッフ情報は、氏名、所属、雇用区分、就業状況、給与マスタ、社保、住民税、扶養、基本シフトなどの基準データ。
給与や勤怠側で同じ値を別管理しない。

扶養情報は `mx_fuyo` を使う。
障害状態は `failure_judgment`、障害手帳は `failure_notebook` を使う。
年末調整PDFでも同じ保存値を表示する。

## 会社・店舗マスタ

会社名、法人番号、住所、店舗コード、店舗名は帳票や売上、年末調整PDFでも使う。
帳票側で会社情報を手入力・固定文字列にしない。

## 手当マスタ

給与・賞与計算の対象可否、控除対象可否、課税区分に関係する。
計算対象から外す項目を画面側だけで非表示にしない。

## カレンダー

勤怠、休日、月次集計に影響する。
祝日取込や休日区分の変更は過去月の再計算に影響する可能性がある。

## 触らないこと

- DBの値を帳票や集計用に別名で複製しない。
- 既存カラムを用途確認なしに削除しない。
- ラベル変更とカラム変更を混同しない。
- 他画面の計算式をマスタ画面側に作らない。
