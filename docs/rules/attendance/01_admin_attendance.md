# 管理側勤怠ルール

## 対象画面

- `admin/attendance`
- `resources/views/admin_v2/work/attendance/index.blade.php`
- `resources/views/admin_v2/work/attendance/daily_table.blade.php`
- `resources/views/admin_v2/work/attendance/page_script.blade.php`

## 役割

管理側は、全スタッフの勤怠確認、修正、確定、未確定、給与反映を行う画面。

## 管理側だけにあるもの

- スタッフ選択
- 勤怠確定
- 勤怠未確定
- 勤怠反映
- 勤怠一括反映
- 給与計算へのリンク
- 管理者向けの確認表示

## 注意

- 確定、未確定は対象スタッフ、対象月だけに効くこと。
- 未来月や別月を巻き込まないこと。
- 勤怠一括反映は、対象月、対象者、給与確定済みかを確認すること。
- 給与確定済みデータを更新する場合は、既存仕様を確認すること。
- 操作後に完了メッセージを出すこと。
- 件数が多い処理は、処理中であることが分かるようにする。

## 表示

- 00:00の未入力は、必要に応じて空欄表示にする。
- シフト所定より変更実績が多い場合は赤。
- シフト所定より変更実績が少ない場合は青。
- 小数点が必要な日数や時間を勝手に整数にしない。

## 給与連動

- 勤怠反映後、給与計算側の勤怠日数、勤務時間、有休、日額交通費が同じ根拠で入ること。
- 個別勤怠反映と勤怠一括反映で計算式を分けない。
