# 勤怠 勝手に触らないもの

## 絶対に守ること

- 管理側とスタッフ側で別計算を作らない。
- 00:00未入力を実時間として扱わない。
- 確定済み勤怠を勝手に更新しない。
- 未来月を勝手に確定済みにしない。
- 個別反映と一括反映で違う計算式を使わない。
- 有休反映を再計算ボタン側へ増やさない。
- 小数が必要な日数や時間を勝手に丸めない。
- 給与反映に使う値と画面表示値をずらさない。

## 変更前に止まる条件

- 画面表示とDB保存値が違う。
- 管理側とスタッフ側で同じ日付の表示が違う。
- どのServiceが正か分からない。
- 確定済みなのに更新できる、または未確定なのに更新できない。
- 給与側の勤怠値と勤怠画面の値が違う。
- 未来月が確定済みになる。
- 00:00が表示や計算に混ざる。
