# Payroll Freeze v1

- Scope: Admin payroll calculation page only
- Route: `/admin/payroll`
- Active controller: `App\Http\Controllers\Admin\PayrollController`
- Frozen files are listed in `.freeze-files.txt`

## Rule

- Changes to payroll must be implemented only in the payroll module/files listed above.
- Do not modify attendance pages or staff site when fixing payroll.
- If unfreeze is required, get explicit user approval per file before editing.
